Why ownership matters

Owning your data is not enough if you rent the system that reasons over it.

When an agent exists only inside someone else’s platform, that platform can change its price, behavior, limits, or access. Your business may own the inputs while still depending on a brain it can lose.

Rented agent

The platform remains in control.

  • Its account is the agent’s home
  • Its model choices shape your options
  • Its logs decide what you can inspect
  • Its terms decide whether you stay
instead

Owned agent

You control the place it lives.

  • Your server holds the runtime
  • Providers can be changed
  • Tasks and changes leave a record
  • You decide what gets added

How the runtime fits together

One controlled layer connects the models, tools, and records you choose.

Aether Many is not another AI model. It is the layer that keeps an agent running, gives it approved capabilities, and records what it did.

Before you follow the build

What Aether Many is—and is not.

Can I install Community Edition today?

No. Aether runs privately today, but the documented public release is still being prepared. The GitHub repository is where that release will appear.

Does it require a local AI model?

No. The design starts with model APIs because they are easier to run reliably, while keeping the runtime separate so local models can be added when they fit.

Does it require Docker or Kubernetes?

No. The default target is a single Ubuntu server with root and bash. Containers and larger clusters are not ruled out; they are simply not required for the first useful setup.

Does self-hosting make an agent private and safe?

Not by itself. Privacy still depends on the models, tools, permissions, retention, and access rules you choose. Aether’s job is to make those choices explicit and inspectable.

Is this the company AI service?

No. Aether Many is the underlying runtime. Works Like Us is the separate business that builds company-specific AI systems.
