Why build another agent?

Running an agent on your server is only the first step toward owning it.

Open agents already prove that useful assistants can run outside a central AI product. Aether Many starts from that progress and applies a harder test: can the owner still understand, change, and keep the system after it learns new skills and grows into a team?

Server control alone

  • Useful state can still hide in a database

Why “Many” is in the name

The answer to one dominant AI is not a different dominant AI.

Aether Many exists to make independent agents practical enough that every person and company can own the intelligence working on its behalf.

Those agents should be able to cooperate and compete under clear rules—without turning one smarter system or one central platform into the permanent owner of the network.

The honest answers before you follow

What Aether Many can promise now.

Can I install Community Edition today?

No. One private Aether runtime works today, but the documented public installer has not been released. The GitHub repository is where that release will appear.

Will Community Edition be free?

That is the plan. Community Edition is being prepared as a free GitHub release. Its license and exact release terms will be stated before the code ships.

Why build this when open agents already exist?

Existing projects have already proved that useful agents can be open and self-hosted. Aether Many focuses on keeping ownership understandable as one agent changes and grows into many: readable operating records, optional capabilities, replaceable models, and reviewable repairs.

Does it require a local AI model?

No. The design starts with model APIs because they are easier to run reliably, while keeping the runtime separate so local models can be added when they fit.

Does it require Docker or Kubernetes?

No. The default target is a single Ubuntu server with root and bash. Containers and larger clusters are not ruled out; they are simply not required for the first useful setup.

Does self-hosting make an agent private and safe?

No. Privacy and safety still depend on the models, tools, permissions, retention, and access rules you choose. Aether Many is meant to make those choices visible; it cannot make every choice safe.

Is this the company AI service?

No. Aether Many is the underlying runtime. Works Like Us is the separate business that builds company-specific AI systems.
